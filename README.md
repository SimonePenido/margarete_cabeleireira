## ✨ Sobre o projeto

Este projeto é um site simples, moderno e responsivo para divulgação dos serviços de **Margarete Cabeleireira**, uma profissional da beleza que busca fortalecer sua presença online e facilitar o contato com clientes.

🔗 **Deploy disponível em:**

## 🚀 Como rodar localmente

1. Clone o repositório:

```bash
git clone https://github.com/SimonePenido/margarete_cabeleireira.git
cd margarete_cabeleireira
```

2. Abra o arquivo index.html no seu navegador preferido ou utilize uma extensão como o Live Server.
